# API 控制台时间显示约定

服务端业务时间在数据库和 API 内继续使用带时区的 UTC ISO-8601，例如：

```text
2026-08-11T08:53:30+00:00
```

控制台面向中国运营人员，页面统一按 `Asia/Shanghai`（UTC+8）展示，因此同一个时刻显示为：

```text
2026-08-11 16:53:30
```

这样可以同时满足：

- 数据库、调度器、跨机器同步继续使用无歧义 UTC；
- 控制台显示与国内 Windows/腾讯云运营时间一致；
- 历史已经保存的 `+00:00` 时间不需要迁移，浏览器会在显示时转换；
- 不会错误产生 `2026-08-11T16:53:30+00:00` 这类“时间数值是北京时间、偏移却仍标 UTC”的伪 ISO 时间。

主控制台 `static/app.js` 使用 `Intl.DateTimeFormat` 并显式指定 `timeZone: "Asia/Shanghai"`，不依赖浏览器自身所在时区。
