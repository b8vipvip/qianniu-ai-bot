无需人工设置。 服务端默认启用 OCR；首次启动会把环境变量或内置默认值写入 SQLite。之后在本页面保存的配置为运行时有效配置，无需重启。关闭 OCR 后，运行时接口会返回 503，客户端可按现有降级链继续处理图片。

OCR 参数

修改后对新 OCR 请求立即生效。并发上限为服务端同时执行的 OCR 推理任务数量。

环境变量默认值

这些参数不是必填项，只用于首次初始化或点击“恢复环境默认值”。

OCR_ENABLED=true
OCR_MAX_IMAGE_BYTES=8388608
OCR_TIMEOUT_SECONDS=8
OCR_MAX_CONCURRENCY=2
OCR_MAX_TEXT_CHARS=6000

识别引擎固定为 RapidOCR/ONNXRuntime；当前没有需要人工选择的模型路径或模型名称。模型由服务端镜像构建过程预取。
