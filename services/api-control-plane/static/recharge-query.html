后台访问 Key 仅以 Fernet 密文保存在 aboter 服务端。查询时由 aboter 登录 ka.k2n.cn 并保存临时会话，不会下发到 Windows Bot，也不会从页面回显。

充值结果自动查询

买家询问充值进度时，Windows Bot 从同一会话里查找客服曾发送的“兑换码：……”；随后由 aboter 登录 ka.k2n.cn，通过后台搜索接口查询该兑换码的最新记录，并按状态自动答复。超时或失败状态会同时创建企业微信人工提醒。

接口与后台登录

aboter 会先使用后台访问 Key 建立临时登录会话，再调用 https://ka.k2n.cn/api.php，使用 action=search、tel=兑换码、page=1 查询记录。旧的 /get_recharge_status 地址会自动迁移。
若同一兑换码存在多条记录，aboter 只采用兑换码完全一致且 ID 最大的最新记录。Windows Bot 只收到状态分类、耗时和回复文案，不会收到后台访问 Key、登录 Cookie、手机号、账号昵称或验证码。

连接测试

输入一个真实兑换码，仅用于即时测试，不会保存。测试会先验证后台 Key 登录，再查询最新的完全匹配记录并按 Bot 实际规则分类。
