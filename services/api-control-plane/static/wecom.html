转人工触发规则

这里的启用规则会同步到已连接的 Windows Bot。可查看、修改、停用、删除或新增关键词。

“账号”默认使用敏感语境匹配：只有同时出现密码、验证码、登录安全、找回、绑定等风险词时才转人工。
“给朋友、另一个账号、再拍月卡、充值”等正常购买场景属于例外，Bot 会直接回复，不再生成企业微信工单。风险词优先于例外词，避免账号安全问题被绕过。
